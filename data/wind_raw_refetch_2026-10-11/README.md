## 原始 JSON 结构说明
- ETF adj/raw 键内均为 Wind get_fund_kline 原始返回（columns/rows 未加工）：
  columns = TIME / OPEN / MATCH(收盘) / HIGH / LOW / TURNOVER / VOLUME / CHANGEHANDRATE / AVPRICE
  单位：TURNOVER=元、VOLUME=股、CHANGEHANDRATE=百分比(%)
- 指数文件为 get_index_kline 原始返回（columns = TIME / OPEN / MATCH / HIGH / LOW / TURNOVER，无 VOLUME/CHANGEHANDRATE）
- TIME 格式：ISO 8601（如 2026-10-09T00:00:00.000+08:00）
- 停牌/缺失日：Wind 直接省略该日（不含在 rows 中），与系统内 -1 占位不同——系统重建时需按 calendar 对齐补 -1
