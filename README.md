# ETF动量轮动系统（ETF Rotation System）

基于聚宽斜率动量策略口径演进的 ETF 量化轮动回测系统。**标的池、因子参数（可任意增删因子）、交易成本、回测区间全部可在 `config.json` 调整**，数据来自 Wind Alice（万得金融数据插件）后复权日K。

## 策略模式

系统内置两种策略模式（参数面板顶部「策略模式」切换，随策略保存）：

1. **动量轮动（TopN）**：默认模式。勾选标的 → 因子排名取前 N 名等权持有（先筛选后排序，TopN 是上限非保底）。
2. **固定比例再平衡（全天候）**：勾选标的后在每行「比例」栏填写持有比例（%），调仓日按比例再平衡——不走动量筛选/择时/走弱期，适合全天候类固定配置（如纳指/黄金/国债/货币各 25%）。比例合计不足 100% 的部分自动买入银华日利（511880.SH 货币ETF，仅展示不参与轮动）；超过 100% 需调整。默认勾选标的等权分配，比例可逐只修改。

## 双视图导航（回测 / 已保存策略）

顶部导航栏提供两个整屏视图（地址栏 hash 路由，刷新后保持）：

- **回测**：第一步选策略模式与标的 → 第二步参数与结果（默认视图）；
- **已保存策略**：独立整屏页面——策略列表（每行名称/创建时间/最新收益与持仓），点击展开详情（指标卡、收益曲线、年度收益表、月度热力图、当前持仓买入份额、调仓记录）；「应用此策略参数到回测」一键跳回回测视图并自动回测。

策略保存在当前链接的存储域（localStorage）。在第一步未解析行情数据时也可直接保存策略；查看详情或应用策略时会自动按需加载行情数据（无需先点「下一步」）。换链接/换设备后，请用旧链接「导出全部」→ 新链接「导入全部」迁移。

## 使用流程（分步式）

打开页面即显示**第一步：选择回测方式与标的**（仅标的池元信息，秒开，无需解析 10MB 行情数据）：

1. 选择**策略模式**：动量轮动（TopN）或 固定比例再平衡（全天候）；
2. 在标的池勾选标的（再平衡模式可逐只填持有比例，默认等权，标题实时显示权重合计）；
3. 点「**下一步 · 开始回测**」——此时才解析行情数据、进入第二步（参数面板 + 回测图表 + 调仓记录），加载中按钮显示提示；
4. 第二步可继续调整参数（因子/筛选/排名/调仓周期/成本/走弱期/择时等）并重跑；点「← 修改标的」可返回第一步修改勾选（状态保留）。

## 策略逻辑（通用因子框架，参数可调）

1. **因子合成得分**（`strategy.factors` 统一因子列表，可任意增删；每项 `usage: "rank"|"filter"` 决定用途，缺省 rank）：
   对每个**排名因子**，先按各自口径算出原始值，再在当日标的全集上做**截面 z-score**（总体标准差，Python `np.std(ddof=0)` 与 JS 手写除以 N 一致），
   加权求和 `得分 = Σ weight × direction × z`；**筛选因子**（`usage:"filter"`）不参与打分，作为候选池过滤条件（先筛选后排序）。因子类型（`kind`）：
   - `roc`（涨幅动量）：原始值 = 窗口首尾涨幅 `收盘价[T] / 收盘价[T-窗口] - 1`，方向默认 +1（涨得越多分越高）；
   - `slope_r2`（斜率动量）：对窗口内对数收盘价做 OLS，原始值 = 年化斜率 × R²（R² 越低越扣分；硬性 R² 门槛可用 `r2` 因子做筛选）；
   - `wslope_r2`（加权斜率动量）：对窗口内对数收盘价做**加权线性回归**（权重=交易日位置线性递增、近期权重更大），原始值 = 加权年化斜率 × 加权 R²；
   - `vol`（波动率）：原始值 = 窗口日收益的年化波动率，**方向默认 -1（低波动加分）**；
   - `risk_adj`（风险调整动量）：原始值 = 窗口涨幅 ÷ 年化波动率，方向默认 +1；
   - `r2`：对数收盘价线性回归的 R²（0~1，一般用作筛选因子，如 R²≥0.4）；
   - `custom`（**自定义公式因子**）：`formula_parts = [{kind, window, coef, op}]`（**最少 2 个成分**），成分间用 `+ − × ÷` 四则运算连接（标准优先级：先乘除后加减），每项为 `coef × 子因子值`，任一成分缺失或除零则该期不参与；
   - 其余 12 类基础因子含 `amount`/`volume`/`rsrs`/`c_vs_ma`/`c_vs_ma_lag`/`ma_vs_ma`/`ma_vs_ma_lag`（见配置表）。
   `config.json` 默认 6 因子：涨幅20(0.20)/涨幅60(0.25)/涨幅120(0.15)/波动率60低波(0.15)/风险调整60(0.15)/斜率动量25(0.10)；
   **网页版「因子管理」面板初始为空、按需自行添加；自定义因子创建后可随时点 ✎ 重新编辑公式与归属**（三面板：因子管理=创建与归属（排名/筛选）+ 筛选条件=过滤阈值 + 排名条件=权重/方向，面板间通过因子归属联动；自定义因子在筛选/排名面板直接显示公式，不设窗口A值）（无因子时策略保持空仓，可参考 config 默认组合添加）。
   单因子（如只留 `[{"kind":"slope_r2","window":25,"weight":1.0}]`）即等价于旧的单一斜率动量口径。
2. **筛选条件**（统一 factors 中 `usage:"filter"` 的因子，全部满足才进入候选池，任何排名策略都可用，默认空；旧版 `strategy.filters` 字段自动兼容为 filter 因子）：
   每项 `{kind, window, op: gte/lte, threshold}`；
   （原 `r2_threshold` 已废除，R² 阈值现为可自行添加/删除/修改的筛选因子）；
   支持 `r2`（R²阈值）、`roc`（涨幅）、`vol`（波动率）、`slope_r2`、`wslope_r2`、`risk_adj`；
   另保留：得分 > `score_floor`（默认 0）、成交量比值（`use_volume_ratio_filter`）、
   均线过滤（`use_ma_filter`，收盘价 > MA(n)）。
3. **走弱期机制**（`use_regime_filter`）：所选自选指数（`strategy.regime_indices`，默认沪深300/中小综指/创业板指/中证A500 全选，网页可自行增减）中至少
   `regime_require_below` 个指数跌破 MA`regime_ma_window`（默认10日，可调）进入走弱期，至少 `regime_require_above` 个站上退出；
   走弱期只从 `overseas_pool` 轮动（`weak_period_mode`: `overseas_pool` / `cash` / `full_pool`），
   并可叠加均线过滤（`weak_period_use_ma_filter`，默认关闭）。
3b. **大盘择时**（`strategy.use_timing`，默认关闭）：开启后所选指数（`timing_indices`，默认沪深300，可多选）**全部站上**
   MA`timing_ma_window`（默认200日，可调）才允许开仓，否则空仓；与走弱期相互独立。
4. **持仓**：按得分降序持有排名区间 N-M 内标的（**等权**，每只 1/(M-N+1)）；全部因子基于 **Wind 后复权（aftype=1）** 收盘价/最高价/最低价/成交额/成交量计算；无合格信号时 `fallback_when_no_signal`：
   `cash` 空仓 或 `gold` 持黄金ETF(518880) / `bond` 持国债ETF(511010) / `money` 持货币ETF(511990)。**该标的未勾选也生效**（引擎自动纳入数据空间、不入候选池）：候选不足区间长度（如排名 1-3 仅 2 只候选）时，剩余仓位自动补持该资产；持仓为空（无候选）时全仓该资产；选 `cash` 则不足部分持现金（原行为不变）。
5. **交易**：调仓周期三选一（`rebalance_mode`）＋数值 `rebalance_interval`＋锚点 `rebalance_anchor`：
   `daily`=每 N 个交易日；`weekly`=每 N 周的**周一**（`anchor=mon`）或**周五**（`anchor=fri`）调仓；`monthly`=每 N 个月的**月初**（`anchor=first`）或**月末**（`anchor=last`）交易日调仓（默认 monthly/1/first）；
   决策日收盘决策，**次日开盘换仓**（无前视）；
   成本 = (佣金 `commission_rate` + 滑点 `slippage_rate`) × 单边换手，在换仓日开盘扣减并计入净值。

| 大盘择时 | `strategy.use_timing` | 默认关闭；开启后所选指数（`timing_indices`，默认沪深300，可多选）**全部站上** MA`timing_ma_window`（默认200日）才允许开仓，否则空仓 |
| 因子列表 | `strategy.factors` | 统一因子列表：任意增删 `{kind, window[, window2, window3], weight[, direction, usage: "rank"/"filter", op, threshold, name, formula_parts]}`；`kind` ∈ `roc`/`slope_r2`/`wslope_r2`/`vol`/`risk_adj`/`r2`/`custom`(公式因子)/`amount`(N日平均成交额,万元)/`volume`(N日平均成交量,万手)/`rsrs`(N日RSRS=最高价对最低价OLS斜率)/`c_vs_ma`(收盘相对近N日均线)/`c_vs_ma_lag`(收盘相对N日前M日均线, window=N平移, window2=M)/`ma_vs_ma`(近N均线相对近M均线, window2=M)/`ma_vs_ma_lag`(近N均线相对M日前O均线, window=N, window2=M平移, window3=O) |
| 因子窗口/权重/方向 | 同上每项 | 例：`{"kind":"vol","window":60,"weight":0.15}`（低波，方向默认 -1）；每个因子可在网页自行设**正向/反向**（`direction`: 1/-1，缺省 vol=-1、其余=1） |
| 卖出冷却 | `strategy.cooldown_days` | 卖出后 N 个交易日不得重新买入（默认 `0` = 不限制）；按决策日索引计算 |
| 仅轮动标的 | `strategy.only_rotation_codes` | 只参与排名与轮动、不实际买入的标的代码数组（网页在标的池每行勾选「仅轮动」，默认空） |
| R²阈值/筛选 | `strategy.factors` 中 `usage:"filter"` 项（或旧 `strategy.filters`，自动兼容） | 如 R²≥0.4：`{"kind":"r2","window":25,"op":"gte","threshold":0.4,"usage":"filter"}`；涨幅≥5%：`{"kind":"roc","window":20,"op":"gte","threshold":0.05,"usage":"filter"}`；波动率≤40%：`{"kind":"vol","window":60,"op":"lte","threshold":0.40,"usage":"filter"}` |
| 自定义公式因子 | `strategy.factors` 中 `kind:"custom"` | `{"kind":"custom","name":"动量增强","weight":0.20,"usage":"rank","formula_parts":[{"kind":"roc","window":20,"coef":1.0},{"kind":"vol","window":60,"coef":0.5},{"kind":"rsrs","window":20,"coef":-0.3}]}`（**≥2 个成分**，四则运算 + − × ÷ 组合） |
| 持有数量 | `strategy.top_n` | `1` ~ `30`（网页可直接输入） |
| 调仓周期 | `strategy.rebalance_mode`（daily/weekly/monthly）+ `rebalance_interval` + `rebalance_anchor` | `monthly`+`1`+`first`（如 `daily`+`3`=每3个交易日、`weekly`+`2`+`fri`=每2周的周五、`monthly`+`1`+`last`=每月末交易日） |
| 成本 | `costs` | 佣金+滑点（单边） |
| 回测区间 | `backtest.start_date / end_date` | 2017-01-01 ~ 2026-09-30 |
| 敏感性网格 | `sensitivity` | 因子窗口缩放×持有数×调仓周期的组合扫描 |
